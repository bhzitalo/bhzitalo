## 📂 Projeto em destaque
### 🧠 PrInt — Pré-Diagnóstico Inteligente

Sistema em desenvolvimento com o objetivo de auxiliar na identificação preliminar de possíveis condições de saúde com base em sintomas informados pelo usuário.

A proposta é utilizar tecnologia para facilitar o acesso à informação e apoiar decisões iniciais, sem substituir avaliação médica profissional.
